Quick Tutorials

1. Deploy this site to Vercel (static)

  1. Sign in to Vercel and Import Project from GitHub.
  2. Choose the repo lisa01morris/XPERT-GLOBAL-TRADE and import.
  3. Set environment variables later if you add server endpoints.
  4. Deploy. Vercel publishes a URL — point your domain in Hostinger to Vercel following their DNS instructions.

2. Connect Supabase (for admin & data)

  1. Create or use your existing Supabase project.
  2. Open SQL Editor and run the file /supabase/schema.sql included in this repo to create example tables.
  3. Admin actions (modify users, issue rewards) must run server-side with SUPABASE_SERVICE_ROLE_KEY. Add that key in Vercel environment variables only when you add server endpoints.

3. Add an admin server endpoint (example)

See /server-examples/supabase-admin.example.js for a Node script that lists users and updates metadata using the service role key. Move this into a protected Next.js API route or a serverless function when you enable server-side code in Vercel.

4. Drive traffic & convert

  • Use the Products page to consolidate your offerings and direct visitors to checkout links.
  • Publish educational guides and case studies (use /pages/tutorials.html and /pages/templates.html).
  • Configure analytics (Google Analytics, Plausible) and track conversions from product checkout links.
