Admin & Management (Supabase)

Manage users

We keep the admin surface minimal and secure. Use Supabase Studio to manage users and data directly:

  1. Go to your Supabase project and open Authentication → Users.
  2. Search, edit user metadata, disable accounts, or reset passwords from Supabase Studio.

If you want a web admin UI that modifies users, implement server endpoints that use SUPABASE_SERVICE_ROLE_KEY (server-only key). Never expose it in client code.

Server example

See /server-examples/supabase-admin.example.js for a Node example. Add the key in Vercel environment variables when you deploy.

Audit log

We include an audit table in /supabase/schema.sql. When you build server endpoints, insert a row into admin_audit for every admin action (who, action, target, timestamp).
